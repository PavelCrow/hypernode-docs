Настройки интерфейса

Откройте Display → Interface Settings…, чтобы настроить внешний вид редактора. Параметры расположения нод находятся отдельно в меню Layout.

Раскладка

  • Layout → Rebuild Layout повторно расставляет видимые ноды по их связям.
  • Layout → Layout spacing… меняет интервалы, которые учитывает раскладка.
  • Layout → Layout rules… открывает правила раскладки.

Отображение

В меню Display собраны параметры показа элементов канвы. Подменю Display → Window относится к размещению частей интерфейса, включая вкладки и Channel Box.

Если после изменения настроек результат выглядит неожиданно, опишите шаги воспроизведения в обратной связи.
